Features

Built for speed — surface the numbers that matter and make timely decisions, whether you're tracking a portfolio or any other spreadsheet.

Portfolio mode

📊 Portfolio Dashboard

Monitor your investments with customizable widgets and real-time data.

📈 Multi-Broker Support

Import positions from Fidelity, Schwab, and other brokers via CSV.

💰 Tax Lot Tracking

Track cost basis and gains/losses with FIFO and weighted average methods.

📅 Event Monitoring

Track earnings dates, dividend payments, and option expirations.

Custom mode

🎨 Custom Dashboards

Turn any CSV or Excel file into its own dashboard — inventories, collections, and more.

🗂️ Data Spaces

Create, reorder, and manage multiple named data spaces, each with its own columns and rows.

🧩 Smart Columns & Widgets

Column types (Text, Number, Currency, Date, URL, Email) auto-detect on import and power widgets like Data Summary and Date Timeline.

📎 Attachments & Receipts

Attach files to any row — receipts, photos, and documents live right alongside your data.

🔒 Private & secure — all data stored locally on your device, in both modes. No cloud sync required.
