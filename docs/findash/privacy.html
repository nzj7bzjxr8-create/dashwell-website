Scope

This is the single Privacy Policy for every app Dashwell LLC publishes: Dashwell (our universal Mac/iPad/iPhone app), Dashwell Portfolio Creator (formerly FinDash, Mac/iPad), and DashCSV (Mac). All three share the same local-first architecture and data practices described below — the differences are which platforms and modes each app includes (only Dashwell has Banking/Transaction mode and iPhone/Apple Wallet support). Wherever this page says "the App," it applies equally to whichever of these apps you're using.

Overview

Dashwell ("we", "us", "our", or "the App") is a portfolio, custom-data, and transaction dashboard application. This Privacy Policy explains how we handle information when you use the App.

Core Principle: The App is local-first. Your financial data stays on your device and is not transmitted to our servers.

1. Data Collection

The App collects minimal data:

  • Data You Import: Portfolio positions, transactions, watchlist data, and custom-mode data that you import via CSV, Excel, or other supported files. This data is stored locally on your device only.
  • Transaction Mode Data (Dashwell only): Spending, budget, and category data you import from bank or card statement exports (CSV), or — only if you explicitly enable it — transaction and balance data for Apple Card, Apple Cash, and Savings with Apple via Apple's FinanceKit framework. See "Financial Data via Apple FinanceKit" below.
  • Market Data: If you configure optional API keys (Alpha Vantage, Tiingo, Massive, FMP), market quotes are fetched from those services. See their privacy policies for details.
  • Settings & Preferences: Your dashboard layout, widget configurations, and preferences are stored locally on your device.

What We Do NOT Collect:

  • Usage analytics or behavioral tracking
  • Hardware information or device identifiers
  • Location data
  • Browsing history or network activity
  • Your email address or personal information (unless you contact support)

2. Financial Data via Apple FinanceKit (Optional, Dashwell only)

Dashwell's Transaction Mode can optionally use Apple's FinanceKit framework to read transaction and balance data for Apple Card, Apple Cash, and Savings with Apple directly from your device's Wallet.

  • Explicit consent: This data is only accessed after you separately authorize it via Apple's system consent prompt. It is off by default.
  • On-device only: FinanceKit data is processed and stored entirely on your device, in the same local SQLite database as your other Dashwell data. It is never transmitted to our servers (we operate none) or shared with any third party.
  • Revocable at any time: You can withdraw FinanceKit access at any time in iOS Settings, or by disabling the feature in Dashwell.
  • Fallback: Users who don't grant FinanceKit access, or whose spending isn't on an Apple-issued account, can use Transaction Mode entirely through manual CSV statement import instead.

3. Data Storage

Local Storage: All financial data is stored in a local SQLite database on your device:

  • Dashwell (macOS): `~/Library/Application Support/Dashwell/dashwell.db`
  • Dashwell Portfolio Creator (macOS): `~/Library/Application Support/Dashwell Portfolio Creator/findash.db`
  • DashCSV (macOS): `~/Library/Application Support/DashCSV/dashcsv.db`
  • iPadOS / iPhone: App Documents directory (sandboxed)

Encryption: Optional files can be password-protected. Passwords are stored in macOS Keychain / iOS Secure Enclave.

API Keys: Optional market data API keys are stored in macOS/iOS Keychain (not transmitted to us).

iCloud Sync (Optional): You may optionally enable iCloud sync to synchronize your database across your devices. This is user-controlled and disabled by default. Encrypted data remains encrypted when synced to iCloud.

4. Data Sharing

The App does not share your data with third parties, except:

  • Market Data APIs: If you configure API keys, market data requests are sent to your chosen provider (Alpha Vantage, Tiingo, Massive, FMP). You control which providers receive your requests. Review their privacy policies.
  • Apple iCloud: If you enable optional iCloud sync, your encrypted database is stored on Apple's servers. You can disable iCloud sync at any time.
  • Apple FinanceKit: If you enable it, Dashwell reads data from Apple's FinanceKit API under Apple's own privacy terms; we do not send this data onward to us or anyone else.
  • CSV/Statement Imports: Broker and bank statement data is imported by you and remains on your device.

5. Your Rights & Control

  • Export Your Data: You can export your data at any time via CSV or other formats.
  • Delete Your Data: You can delete any data locally from your device. Clearing app data removes the database entirely.
  • Disable API Calls: You can remove API key configurations to stop sending data to market data providers.
  • Disable FinanceKit Access: You can revoke Apple Card/Cash/Savings access at any time in iOS Settings or in Dashwell.
  • Disable iCloud Sync: You can turn off iCloud sync in settings to keep all data local.

6. Data Security

We implement security measures appropriate for a local-first application:

  • Optional password protection for files
  • Keychain storage for sensitive credentials (macOS/iOS standard)
  • HTTPS for all API calls (when API keys are configured)
  • No transmission of financial data to our servers

Responsibility: You are responsible for maintaining your device security, password strength, and protecting your Keychain access.

7. Third-Party Services

If you configure optional market data API keys, or enable optional Apple integrations, data is shared with:

  • Alpha Vantage - https://www.alphavantage.co/
  • Tiingo - https://www.tiingo.com/
  • Massive - https://www.massive.com/
  • FMP (Financial Modeling Prep) - https://financialmodelingprep.com/
  • Apple iCloud (if sync enabled) - https://www.apple.com/icloud/
  • Apple FinanceKit (Dashwell, if enabled) - https://developer.apple.com/financekit/

Review their privacy policies before using their services.

The App is not intended for children under 13. We do not knowingly collect information from children under 13.
