## Print the flyer to PDF

1. Open `flyer.html` in Safari or Chrome (double-click, or drag onto a browser window).
2. **File → Print** (or ⌘P).
3. Choose **Save as PDF** / **PDF → Save as PDF**.
4. Paper size: **US Letter**. Margins: default is fine (the page sets `@page` letter).
5. Turn off headers/footers if the browser adds a URL or date.
