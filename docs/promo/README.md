# Promo hub (Dashwell Solutions)

Public URL: **https://dashwellsolutions.com/promo/**

Shared marketing/promo area for **all Dashwell Solutions apps**. Live campaigns start with the unified **Dashwell** app; the hub and folder layout are designed so Portfolio / Dashboard Creator, DashCSV, SheetStand, and FormatStand can each get kits later without inventing placeholder product cards.

## Live now

| Path | App | Contents |
|------|-----|----------|
| [`retirement/`](retirement/) | Dashwell 1.4 | Flyer, SMS/email/social drafts, [App Store Connect paste kit](retirement/app-store.html) |

Nav item **Promo** appears site-wide. Sitemap includes `/promo/` and the retirement ASC paste page.

## Expansion model

1. Add `docs/promo/<campaign-slug>/` with materials (flyer HTML, drafts, optional `app-store.html` paste kit).
2. Add one real campaign card on [`index.html`](index.html) when the kit is ready — **do not** invent empty cards for other apps.
3. Keep App Store creative paste text on the site; flyer URLs belong on `/promo/`, not inside App Store creative fields.
4. Product detail pages stay under `/dashwell/`, `/findash/`, `/dashcsv/`, `/sheetstand/`, `/formatstand/` — Promo is for shareable release kits, not a second catalog.
